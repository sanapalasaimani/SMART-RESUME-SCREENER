Smart Resume Screener

How to Run & How it Looks

This video demonstrates how to run our native Java application and explains its features.

(Duration: exactly 1 minute and 10 seconds)

1. How to Compile and Run

The application is built in Java and requires no external package managers.

# Compile the source code: javac -cp "lib/*" src/*.java # Run the GUI application: java -cp "src;lib/*" SmartResumeScreenerGUI

2. The Graphical User Interface (GUI)

When you run the command, the Java Swing GUI opens automatically.

3. Running the Screener

Paste your job description into the top box, and browse for the folder containing your PDF/TXT resumes.

4. LLM Processing

The application parses the PDFs using Apache PDFBox and sends them to the Groq LLM API for intelligent extraction and scoring.

Found 1 resumes. Processing via LLM API... This may take a moment per resume... Parsing: john_doe.txt ...

5. Reviewing the Results

Candidates are scored (1-10) and ranked. The LLM extracts their skills and justifies the score.

Candidate: john_doe.txt Score: 9/10 Skills: Java, Python, SQL, REST APIs, Git Justification: The candidate has strong Java development background which perfectly aligns with the job description...

6. Persistent Storage in GitHub

Finally, all output is safely stored locally in a `database.csv` file, making it easy to track historical applicant data!
