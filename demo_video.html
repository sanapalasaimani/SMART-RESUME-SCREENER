Smart Resume Screener

Project Submission Demo

This video demonstrates a fully functional, zero-dependency native Java application for intelligently screening resumes.

Architecture Overview

Built completely in Java 17 without external package managers.

Uses native Java HttpClient to connect to the Groq LLM API.

Uses native Java Swing for the Graphical User Interface.

Includes a single dependency (Apache PDFBox) securely placed in a lib folder for robust PDF parsing.

LLM Prompting Strategy

"Compare the following resume with this job description. Extract structured data: skills, experience, education. Compute a match score between candidate and job description (1-10). Provide a justification. Return exactly a JSON object (and nothing else)."
